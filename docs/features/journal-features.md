## 一、抽象方法

Journal 是 PM 所有信息的**唯一入口**，承担"零组织成本输入"职责。从场景反推功能：

```
PM 场景动作                →  Journal 需要的能力
─────────────────────────────────────────────
口述需求/语音               →  多模态输入
粘贴竞品截图               →  图片块 + OCR
粘贴数据看板截图           →  图片块 + 数据识别
@张三 任务                 →  @提及 + 行动项识别
"决策：砍掉金卡"           →  决策块自动识别
"转化率8%"                 →  数据指标块
三个月前的关联             →  跨日期语义召回
按周出周报                 →  日期范围聚合
按竞品名查全部输入         →  标签/主题筛选
会议纪要结构化             →  模板块 + 字段抽取
```

## 三、功能详述

### 3.1 输入能力

#### J-05 图片块【既有，增强】

**场景驱动**：PM 频繁粘贴竞品截图、数据看板截图、用户反馈截图。

**需求**：
- 支持粘贴/拖拽图片，存入 `<workspace>/assets/journal/YYYY-MM-DD/<hash>.png`
- 图片块在 Markdown 中以 `![](相对路径)` 形式持久化
- **增强**：图片块下方可附加一行文字说明，作为该图的语义注解（参与向量化）

---

#### J-11 语音输入【新增】

**场景驱动**：场景1 用户访谈现场、场景5 会议中不便打字。

**需求**：
- Journal 工具栏提供"语音输入"按钮，调用本地或云端 ASR
- 转写文本作为普通 Block 插入当前光标位置
- 保留原始音频文件引用（可选，存 `<workspace>/assets/journal/YYYY-MM-DD/<hash>.wav`）
- 转写完成后 AI 自动分段为多个 Block

**优先级**：P1（非 MVP 阻塞项，但高频价值）

---

#### J-12 截图 OCR 识别【新增】

**场景驱动**：场景2 竞品截图中的功能文案、场景6 数据看板截图中的数字。

**需求**：
- 图片块右键菜单"识别文字"
- OCR 结果作为图片块的隐藏 `alt`/`data-ocr` 属性，参与向量化
- 数据看板截图额外尝试结构化识别（识别表格/数字），存为 `data-extracted` 属性

**优先级**：P2

---

#### J-17 块模板/快速插入【新增】

**场景驱动**：场景5 会议纪要固定结构、场景6 数据观察固定字段。

**需求**：
- 输入 `/` 唤起模板菜单（Slash Menu 已在 Tiptap 编辑器中规划）
- 内置 PM 常用模板：

**保留模板**：仅保留碎片化的输入型模板（用户需求 / 用户访谈 / 竞品观察 / 产品数据 / 会议纪要）。长内容的结构化输出模板（如 PRD、MRD）不属于 Journal 输入范畴，归入 Project 作品创作空间，不在 Journal Slash Menu 中提供。

| 模板 | 展开内容 |
| :--- | :--- |
| `/requirement` | `- 需求：{}\n- 用户故事：作为一名{角色}，我希望{功能}，以便{价值}\n- 优先级：P0/P1/P2` |
| `/interview` | `## 用户访谈 - {对象}\n- 背景：\n- 原话：\n- 痛点：` |
| `/competitor` | `## 竞品观察 - {竞品名}\n- 动态：\n- 影响：` |
| `/data` | `- 指标：{} 数值：{} 同比：\n- 假设：\n- 验证：` |
| `/meeting` | `## 会议纪要 - {标题}\n- 时间：\n- 参会：\n- 决策：\n- 行动项：` |

- 支持用户自定义模板，存 `<workspace>/templates/`

**优先级**：P1

---

### 3.2 组织能力

#### J-13 @提及人员【新增】

**场景驱动**：场景5 行动项 `@张三 8.10前更新PRD`。

**需求**：
- 输入 `@` 唤起人员补全（人员列表来自本地通讯录或手动维护）
- @提及以 `@[[人员:张三]]` 形式持久化，建立人员维度索引
- 支持按人员筛选其所有相关 Block（用于跟踪某人待办）
- **不集成第三方 IM**，仅本地人员库

**优先级**：P1

---

#### J-14 决策块标记【新增】

**场景驱动**：场景5 "决策：三级会员改为两级"，需可追溯。

**需求**：
- 行首输入 `>! 决策：` 触发决策块标记（视觉：左侧黄色竖条 + 图标）
- 决策块强制字段：决策内容 / 原因 / 日期
- 决策块进入独立索引表 `decisions`，支持：
  - 按主题查看某功能的所有决策时间线
  - 反思流可引用历史决策（"该功能去年Q4被否决，原因ROI不足"）
- 在 Project 撰写 PRD 时，AI 可召回相关历史决策

**优先级**：P1

---

#### J-15 数据指标块【新增】

**场景驱动**：场景6 数据观察需被结构化捕获，便于归因关联。

**需求**：
- 行首输入 `#data` 或使用 `/data` 模板触发数据块
- 字段：指标名 / 数值 / 时间 / 同比 / 环比 / 备注
- 数据块进入 `metrics` 索引表
- 反思流可基于 `metrics` 表做异常检测与历史归因关联

**优先级**：P2

---

#### J-16 引用块（@引用历史 Block）【新增】

**场景驱动**：场景3 PRD 撰写时需引用历史调研原话；场景6 数据异常时引用上次同类异常。

**需求**：
- 输入 `((` 唤起历史 Block 语义搜索弹窗
- 选中后插入为引用块：`> {block内容}\n> — @journal/2026-05-16#block-3`
- 被引用的 Block 建立 `quoted_by` 反向链接
- 在被引用 Block 详情中显示"被 N 处引用"

**与既有 `[[页面]]` 双链的区别**：`[[]]` 链接页面，`(()` 链接具体 Block。

**优先级**：P1

---

### 3.3 导航与检索

#### J-18 日期跳转/日历导航【既有，增强】

**场景驱动**：PM 需回看某天会议、某周需求输入。

**需求**：
- Journal 顶部日期选择器（【既有】）
- **增强**：日历视图（月视图），每日单元格显示：
  - 当日 Block 数量
  - 当日是否含 TODO 未完成（红点）
  - 当日是否含决策块（黄点）
  - 当日是否含数据块（蓝点）
- 点击日期跳转该日日志页

**优先级**：P1

---

#### J-19 按日期范围筛选【新增】

**场景驱动**：场景4 版本规划需看某段时间需求密度；场景5 周报需聚合本周。

**需求**：
- 侧边栏"筛选"区提供日期范围选择
- 选中范围后，主区域展示该范围内所有 Block 的扁平列表（按时间倒序）
- 支持"本周/本月/本季度/自定义"快捷选项
- 该视图下支持二次按标签/主题/人员筛选

**优先级**：P1

---

#### J-20 按标签/主题筛选【新增】

**场景驱动**：场景2 查看竞品X所有历史观察；场景4 查看某主题需求密度。

**需求**：
- 侧边栏"筛选"区：
  - 标签云（按使用频次排序）
  - 主题列表（来自 Wiki 主题聚类）
- 多选筛选，结果实时更新主区域
- 筛选状态可保存为"快捷视图"（如"竞品X追踪"）

**优先级**：P1

---

#### J-21 按来源类型筛选【新增】

**场景驱动**：PM 需区分"用户访谈输入"vs"老板需求"vs"竞品观察"。

**需求**：
- 来源类型枚举：用户访谈 / 竞品观察 / 数据观察 / 会议 / 老板需求 / 自发思考 / 其他
- Block 可手动打来源标签，或由模板自动带入（`/interview` → 来源=用户访谈）
- 侧边栏支持按来源筛选

**优先级**：P2

---

### 3.4 AI 增强

> AI 增强遵循 PRD §3.1"后台无感知"原则，不干扰编辑体验。

#### J-23 AI 自动决策点提取【新增】

**场景驱动**：场景5 会议纪要中决策散落，需自动归集。

**需求**：
- 当 Block 内容匹配决策模式（含"决定/决策/敲定/确认/砍掉/采纳"等关键词或语义）
- AI 提示"检测到决策，是否标记为决策块？"
- 用户确认后转为 J-14 决策块格式
- 批量处理：对历史 Journal 全量扫描，生成决策点清单供用户复核

**优先级**：P1

---

#### J-24 AI 自动行动项提取【新增】

**场景驱动**：场景5 会议纪要行动项需跟踪。

**需求**：
- 识别含 `@人员` + 动词（更新/输出/对齐/评审）+ 时间的 Block
- 自动转换为 TODO 块，状态=TODO
- 行动项进入"待办中心"视图（跨日期聚合所有未完成 TODO）
- 完成后在原 Block 自动标记 DONE

**优先级**：P1

---

#### J-25 AI 自动用户故事提取【新增】

**场景驱动**：场景3 PRD 撰写需结构化用户故事。

**需求**：
- 对标记来源=用户访谈的 Block，AI 提取 As-A 句式：
  `作为一名{角色}，我希望{功能}，以便{价值}`
- 提取结果存入 `user_stories` 索引表，关联原 Block
- 在 Project PRD 撰写时，AI 按主题召回相关用户故事

**优先级**：P2

---

#### J-26 AI 跨日期语义关联提示【新增】

**场景驱动**：场景1 "优惠券规则"自动关联3个月前反馈；场景6 转化率下降关联首页改版。

**需求**：
- 新 Block 写入后，AI 检索语义相似的历史 Block（相似度 > 阈值）
- 在新 Block 下方以折叠面板形式展示"相关历史（N条）"
- 用户可展开查看，点击跳转原 Block
- 关联关系存入 `semantic_links` 表（【既有】语义链接机制的显式呈现）

**优先级**：P1（核心价值点）

---

#### J-27 AI 数据异常归因关联【新增】

**场景驱动**：场景6 数据异常需自动关联可能原因。

**需求**：
- 当 J-15 数据块的数值超出历史基线（如环比波动 > 20%）
- AI 自动检索同期（前后7天）的相关事件 Block（如改版、活动、故障）
- 在数据块下方展示"疑似归因"列表
- 归因关系存入 `data_correlations` 表

**优先级**：P2

---

#### J-28 AI 周报草稿生成【新增】

**场景驱动**：场景5 PM 每周需输出周报。

**需求**：
- Journal 侧边栏"快捷操作"提供"生成本周周报"
- AI 按主题聚合本周所有 Block：
  - 按主题分组（来自 Wiki 主题聚类）
  - 每个主题下提取关键决策、完成行动项、待办行动项、数据变化
- 生成结果作为新 Project 草稿，用户编辑后导出
- 周报模板可自定义

**优先级**：P1

---

#### J-30 块内联 AI 对话【新增】

**场景驱动**：场景3 PRD 撰写时对某 Block 追问"展开异常处理"。

**需求**：
- 选中 Block 后右键"AI 对话"
- 在 Block 下方展开对话框，上下文为该 Block + 相关语义召回的历史 Block
- 对话结果可"插入为新 Block"或"追加到当前 Block"
- 对话历史不持久化（与 Project 中的 AI Skills 不同，此处为轻量即时对话）

**优先级**：P2

## 五、优先级与分期建议

### P0（MVP 必备，无此项场景不闭环）
- J-01~J-10 既有基础能力
- J-16 引用历史 Block（PRD 撰写素材召回的载体）
- J-22 全局语义检索（已有）
- J-26 跨日期语义关联提示（核心卖点"自动结晶"的显式呈现）

### P1（高价值，建议 MVP 后首版）
- J-17 块模板（降低结构化输入成本）
- J-13 @提及 + J-24 行动项提取（会议场景闭环）
- J-14 决策块 + J-23 决策点提取（决策可追溯）
- J-19/J-20 筛选导航（知识积累后必备）
- J-28 周报生成（高频输出）

### P2（增强体验，后续迭代）
- J-11 语音输入
- J-12 截图 OCR
- J-15 数据指标块 + J-27 异常归因（数据场景深化）
- J-21 来源类型筛选
- J-25 用户故事提取
- J-30 内联 AI 对话
