# 基础功能需求 — 设置与系统

> 本文档从 [prd.md](prd.md) §四 拆分。
> 涵盖首次启动引导、设置页面和版本升级等基础功能。

---

## 一、首次启动欢迎页

首次启动时，引导用户完成以下配置：

1. **选择工作空间**：指定 Markdown 文件存储目录
2. **启用本地智能**：下载 embedding + reranker + 语言模型（约 4.5 GB）
3. **启用云端智能**（可选）：选择服务商并填入 API Key，设置月度限额
4. **快速上手**：展示核心交互流程，引导用户完成第一条记录

---

## 二、设置

| 设置项            | 说明                                          |
| :---------------- | :-------------------------------------------- |
| **本地模型管理**  | 模型下载/切换/删除的可视化管理                |
| **云端 API 配置** | OpenAI 兼容 API Key + Base URL 配置           |
| **智能模式**      | 独立开启/关闭本地智能和云端智能               |
| **模型路由**      | 调整任务路由优先级（如"强制所有 LLM 走云端"） |
| **通用设置**      | 语言（中/英文）、主题、快捷键                 |
| **数据管理**      | 工作空间路径、数据库迁移、备份与恢复          |

---

## 三、升级

- **版本更新检查**：自动检测新版本，提示用户下载
- **模型更新**：当有新模型可用时，在模型管理器中提示
- **功能迭代**：Phase 1 → Phase 2（反思流、跨设备同步）→ Phase 3（多格式导出、插件系统）

---

## 四、Phase 1 功能范围

| 功能              | 优先级 | 说明                                |
| :---------------- | :----- | :---------------------------------- |
| 本地模型管理      | P0     | Embedding/Reranker/LLM 下载切换     |
| 云端 API 配置     | P0     | OpenAI 兼容 API Key + Base URL 配置 |
| 云端/本地模型切换 | P0     | 用户选择生成任务使用云端或本地模型  |
| 首次启动欢迎页    | P0     | 引导用户完成初始配置                |
| 设置页面          | P0     | 模型管理、API 配置、通用设置        |
| Electron 打包     | P0     | Windows / macOS / Linux 安装包      |
| 国际化（中/英文） | P1     | i18n 完整覆盖                       |
