# Wiki 功能需求 — 概念网络与主题聚类

> 本文档从 [prd.md](prd.md) §3.2 拆分，描述 Wiki 模块的完整功能设计。
> Wiki 是 AI 自动整理的知识体系视图，包含概念网络和主题聚类两大核心模块。

---

## 一、概念网络（Concept Graph）

概念网络是 AI 从用户所有语义块中自动提取的**概念实体及其关联关系**的**气泡图**可视化呈现。

### 1.1 气泡图数据映射

| 气泡特性          | 对应的数据含义                                    |
| :---------------- | :------------------------------------------------ |
| **气泡大小**      | 概念关联的语义块数量（Block 越多，气泡越大）      |
| **气泡位置/距离** | 概念之间的语义相似度（共享 Block 越多，位置越近） |
| **气泡颜色**      | 概念所属的主题（同一主题的概念颜色相近）          |
| **气泡内标签**    | 概念名称                                          |

### 1.3 基础交互（MVP）

| 交互     | 行为                                                 |
| :------- | :--------------------------------------------------- |
| **悬停** | 气泡放大，显示概念名称 + Block 数量 + 所属主题       |
| **点击** | 右侧弹出详情面板，显示该概念的所有关联 Block 列表    |
| **缩放** | 滚轮缩放画布（针对概念较多的情况）                   |
| **拖动** | 拖动画布平移；拖动气泡调整位置（仅临时，刷新后重置） |

### 1.5 筛选与过滤（Phase 2）

| 功能                  | 说明                                     |
| :-------------------- | :--------------------------------------- |
| **按主题筛选**        | 只显示某个主题下的概念                   |
| **按时间范围筛选**    | 只显示近期有更新的概念（updated_at）     |
| **按 Block 数量筛选** | 只显示关联 Block 数大于 N 的概念         |
| **搜索概念**          | 输入关键词，高亮匹配的气泡，未匹配的淡出 |

### 1.6 相似概念合并（Phase 2）

当两个或多个概念语义高度相似（共享 Block 比例超过阈值，如 60%），系统提示建议合并：

| 阶段     | 行为                                                                       |
| :------- | :------------------------------------------------------------------------- |
| **检测** | AI 自动检测语义相似度高的概念对，在气泡图上以虚线边框或闪烁提示            |
| **预览** | 悬停提示区域，高亮显示将被合并的概念及其共享的 Block 列表                  |
| **确认** | 用户确认合并后，选择一个保留的概念名称，或输入新名称                       |
| **结果** | 被合并的概念的 Block 和关联关系全部转移到保留概念下，更新 evolving_summary |

**合并流程示意：**

```
检测到相似概念：「LanceDB」↔「LanceDB 向量库」
  共享 Block 比例：75%
  ┌─────────────────────────────────┐
  │  是否合并这两个概念？            │
  │                                 │
  │  保留名称：○ LanceDB            │
  │           ○ LanceDB 向量库      │
  │           ○ 自定义：________    │
  │                                 │
  │  合并后将包含 15 个语义块        │
  │  [确认合并]  [忽略]  [稍后提醒] │
  └─────────────────────────────────┘
```

### 1.7 关联跳转（Phase 2）

- 双击气泡 → 跳转到概念详情页
- 在概念详情页点击"查看网络" → 回到气泡图并高亮该概念

## 二、主题聚类（Topic Clustering）

主题是 AI 自动结晶的核心产物，也是连接"知识整理"和"高效创作"的桥梁。

```
AI 自动聚类 → 生成主题 → 主题卡片列表 → 查看详情 → 快速创建作品
```

**卡片内容：**

| 元素           | 说明                            |
| :------------- | :------------------------------ |
| **图标**       | 📚 固定（或主题类型图标）       |
| **主题名称**   | AI 自动生成的名称（用户可编辑） |
| **语义块数量** | 该主题包含的 Block 总数         |
| **概念数量**   | 该主题关联的概念总数            |
| **更新时间**   | 最近一次有 Block 关联的时间     |
| **状态标签**   | "待确认"（可选，默认自动确认）  |
| **操作按钮**   | [查看详情] [删除] [快速创作]    |

**排序与筛选：**

- **排序**：按更新时间（默认）、按 Block 数量、按名称
- **筛选**：已删除主题（回收站）、按时间范围

### 2.3 主题生命周期管理

#### 自动创建

```
AI 聚类检测到高频概念簇
    ↓
生成候选主题（名称 + 摘要 + 关联 Block）
    ↓
自动创建主题（状态：active）
    ↓
出现在主题卡片列表中
```

#### 删除（软删除）

```
用户点击"删除主题"
    ↓
弹出确认框："主题将被移至回收站，可随时恢复"
    ↓
状态变为 deleted
    ↓
从主题列表消失，出现在回收站
```

#### 恢复与彻底删除

| 操作         | 说明                                       |
| :----------- | :----------------------------------------- |
| **恢复**     | 从回收站将主题恢复为 active                |
| **彻底删除** | 永久删除主题及其所有关联关系（需二次确认） |

> 回收站入口：主题列表顶部右侧的"回收站"图标。

### 2.4 基于主题快速创建作品

这是主题的核心价值闭环——从"整理"到"创作"。

**入口：**

- 主题详情面板底部的 [快速创作作品] 按钮
- 主题卡片上的 [快速创作] 快捷操作（鼠标悬浮时显示）

**创建流程：**

```

```
