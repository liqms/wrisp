# Reflection 功能需求 — 反思流

> 本文档从 [prd.md](prd.md) §3.2 反思流部分拆分。
> 反思是 Wrisp 的**"元认知层"**——让系统不仅存储知识，还能分析知识的结构、变化和潜在价值。
> 反思流属于 Phase 2 功能范围。

---

## 一、反思类型总览

| 类别     | 反思类型     | 核心价值                 | AI 依赖 |
| :------- | :----------- | :----------------------- | :------ |
| 模式发现 | 热点主题识别 | 发现近期关注焦点         | 中      |
|          | 周期性规律   | 识别记录习惯的周期模式   | 低      |
|          | 高频概念     | 发现反复出现的核心概念   | 低      |
| 趋势分析 | 兴趣漂移     | 追踪关注点的转移         | 中      |
|          | 知识增长     | 展示知识量的积累趋势     | 低      |
|          | 概念演化     | 概念含义的变化轨迹       | 高      |
| 矛盾检测 | 观点冲突     | 发现不同时间的矛盾观点   | 高      |
|          | 目标偏离     | 当前行动与长期目标不一致 | 中      |
| 知识缺口 | 缺失关联     | 发现未建立的关键连接     | 中      |
|          | 延伸探索     | 推荐相关的未知领域       | 高      |
| 行为洞察 | 活跃提醒     | 长期未记录的提醒         | 低      |
|          | 习惯肯定     | 正向强化记录习惯         | 低      |
| 创作启发 | 素材聚合     | 为特定主题聚合可用素材   | 中      |
|          | 灵感触发     | 基于历史记录生成新想法   | 高      |

## 二、详细分类与触发逻辑

### 类别一：模式发现（Pattern Discovery）

识别用户知识活动中的重复模式。

| 类型           | 名称         | 触发逻辑                                | 示例文案                                                                                   |
| :------------- | :----------- | :-------------------------------------- | :----------------------------------------------------------------------------------------- |
| **热点主题**   | 近期关注焦点 | 过去 7 天新增 Block 数量最多的概念/主题 | "你最近一周关于'向量数据库'的讨论热度上升了 80%，新增了 6 个相关 Block。"                  |
| **周期性规律** | 记录节奏分析 | 分析用户历史记录的时间分布              | "你通常在周二和周四记录最多，本周四的记录量比平时高 40%。"                                 |
| **高频概念**   | 核心概念识别 | 全局统计被引用最多的概念                | "你的知识体系中，'本地优先'是出现频率最高的概念（47 次引用），其次是'语义搜索'（32 次）。" |

### 类别二：趋势分析（Trend Analysis）

追踪知识在时间维度上的变化。

| 类型         | 名称          | 触发逻辑                           | 示例文案                                                                                        |
| :----------- | :------------ | :--------------------------------- | :---------------------------------------------------------------------------------------------- |
| **兴趣漂移** | 关注转移检测  | 对比不同时间段的概念热度排序变化   | "你的关注点正在从'前端框架'（-45%）转向'AI 推理引擎'（+62%），这种趋势已持续 3 周。"            |
| **知识增长** | 知识积累报告  | 统计新增 Block/概念/主题的数量变化 | "本月你新增了 23 个 Block、5 个概念和 2 个主题，知识体系增长率为 12%，与上月持平。"             |
| **概念演化** | 观点/含义演化 | 对比同一概念在不同时间的描述变化   | "你关于'本地优先'的理解从'数据存本地'演变为'完整的隐私保护理念'，这期间新增了 8 个相关 Block。" |

### 类别三：矛盾检测（Contradiction Detection）

发现知识体系中的不一致或冲突。

| 类型         | 名称             | 触发逻辑                                | 示例文案                                                                                                 |
| :----------- | :--------------- | :-------------------------------------- | :------------------------------------------------------------------------------------------------------- |
| **观点冲突** | 观点矛盾发现     | 在同一主题/概念下，识别出逻辑矛盾的表述 | "你在 5 月 10 日写道'本地模型已足够'，但在 6 月 15 日写道'复杂推理必须上云端'。这两个观点存在潜在矛盾。" |
| **目标偏离** | 行动与目标不一致 | 用户设定的目标 vs 实际记录内容的偏差    | "你本季度的目标是'掌握向量数据库'，但最近 2 周的相关记录仅占全部记录的 5%，建议重新聚焦。"               |

### 类别四：知识缺口（Knowledge Gap）

发现知识体系中缺失或薄弱的部分。

| 类型         | 名称         | 触发逻辑                                               | 示例文案                                                                                              |
| :----------- | :----------- | :----------------------------------------------------- | :---------------------------------------------------------------------------------------------------- |
| **缺失关联** | 潜在连接建议 | 检测到两个高频概念从未或很少同时出现，但语义上高度相关 | "你经常讨论'LanceDB'和'IVF-PQ 索引'，但从未将'LanceDB'与'分布式部署'关联起来。是否有意探索这个方向？" |
| **延伸探索** | 未知领域推荐 | 基于已有知识推荐相邻领域                               | "你已深入研究'向量数据库'，建议探索'RAG 系统'——该领域与你的知识重叠度高，且你当前没有相关记录。"      |

### 类别五：行为洞察（Behavioral Insight）

关注用户的记录行为和习惯。

| 类型         | 名称         | 触发逻辑                             | 示例文案                                                                                |
| :----------- | :----------- | :----------------------------------- | :-------------------------------------------------------------------------------------- |
| **活跃提醒** | 记录断点提醒 | 检测到连续 N 天（如 7 天）无新增记录 | "你已经 7 天没有记录新内容了。上次记录是关于'向量数据库选型'的思考，要继续这个话题吗？" |
| **习惯肯定** | 正向强化     | 检测到连续记录超过 N 天              | "你已经连续 30 天保持记录习惯，累计记录了 156 个 Block。这是一个了不起的成就！"         |

### 类别六：创作启发（Creation Inspiration）

基于已有知识激发新的创作。

| 类型         | 名称         | 触发逻辑                           | 示例文案                                                                                                                   |
| :----------- | :----------- | :--------------------------------- | :------------------------------------------------------------------------------------------------------------------------- |
| **素材聚合** | 主题素材盘点 | 针对某个已有主题，汇总所有可用素材 | "你的'向量数据库'主题下已有 23 个 Block 和 5 个概念，可以整理为一篇技术调研报告。素材覆盖了选型对比、性能测试和部署方案。" |
| **灵感触发** | 跨领域灵感   | 将两个不相关领域结合，生成新想法   | "你同时关注'咖啡文化'和'本地优先架构'——'本地咖啡品鉴指南'和'本地优先 App'这两个方向是否有交叉点？"                         |

## 三、反思的数据模型

```sql
CREATE TABLE reflections (
    id TEXT PRIMARY KEY,
    type TEXT NOT NULL,              -- 反思类型（见上表）
    title TEXT NOT NULL,             -- 反思标题
    content TEXT NOT NULL,           -- 反思内容（用户可读的自然语言）
    confidence REAL DEFAULT 0.0,     -- AI 置信度（0-1）
    severity TEXT DEFAULT 'info',    -- 严重程度：info / warning / important
    status TEXT DEFAULT 'pending',   -- pending / read / archived
    related_block_ids TEXT,          -- JSON 数组，关联的 Block ID
    related_concept_ids TEXT,        -- JSON 数组，关联的概念 ID
    related_topic_ids TEXT,          -- JSON 数组，关联的主题 ID
    metadata TEXT DEFAULT '{}',      -- 扩展数据（如数值对比等）
    created_at TEXT NOT NULL,
    updated_at TEXT NOT NULL
);
```

### 4.2 反思卡片设计

每个反思卡片包含：

- **类型图标**：🔥（热点）、⚡（冲突）、📈（趋势）、💡（灵感）、⏰（提醒）
- **严重程度色条**：左侧 3px 色条（灰色=info，黄色=warning，红色=important）
- **标题**：简明扼要
- **内容**：1-2 句完整描述
- **操作按钮**：查看详情、标记已读、关联操作（如"创建作品"）
- **元信息**：生成时间
