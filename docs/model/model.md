# Pentip AI 模型方案

**版本**：v3.0\
**最后更新**：2026-06-28\
**核心理念**：

| 目标       | 要求                                    |
| ---------- | --------------------------------------- |
| 本地优先   | 数据完全本地可控                        |
| AI Native  | AI 能力嵌入记录、整理、推演、创作全流程 |
| 中英文优先 | 统一语义空间支持中英文混合              |
| 零配置     | 安装即用，无需 Python / Ollama / Docker |

---

## 一、硬件配置要求

| 配置项      | 最低要求                        | 推荐配置                       | 说明                                                                |
| ----------- | ------------------------------- | ------------------------------ | ------------------------------------------------------------------- |
| 内存 (RAM)  | **8 GB**                        | 16 GB 或更高                   | 8GB 可同时运行 embedding + reranker + 4B 量化语言模型（峰值约 7GB） |
| 磁盘空间    | **≥3 GB**                       | ≥10 GB                         | 首次自动下载约 2.2 GB，语言模型额外 1-3 GB，知识库按需增长          |
| 操作系统    | Windows 10/11, macOS 11+, Linux | 同左，macOS 推荐 Apple Silicon | MLX 仅限 Apple Silicon，其余平台使用 llama.cpp                      |
| 网络        | 首次启动必须联网（下载模型）    | 视配置而定                     | 开启本地智能后续可完全离线；开启云端智能需网络调用 API              |
| GPU（可选） | 无要求                          | NVIDIA GTX 1060 6GB 或更高     | 支持 CUDA / Vulkan 加速，可显著提升推理速度                         |

## 二、模型列表

### 2.1 必须模型（首次启动自动下载）

| 模型                    | 参数 | 量化大小  | 格式         | 用途说明                                       |
| ----------------------- | ---- | --------- | ------------ | ---------------------------------------------- |
| **jina-embeddings-v3**  | 572M | \~1.15 GB | Transformers | 多语言语义向量化、相似度计算、聚类、边界检测   |
| **bge-reranker-v2-m3**  | 568M | \~1.14 GB | Transformers | 搜索结果精排、相关性重排序，提升语义搜索准确率 |
| **Qwen3.5-4B-Instruct** | 4B   | \~2.5 GB  | GGUF/MLX     | 通用本地生成，综合效果最佳，中英极强           |

> 以上三个模型下载解压后共约 **4.5 GB**，是系统运行的基础。

### 2.2 云端模型（用户自选 API）

支持任何 **OpenAI 兼容** 的 API 端点，包括但不限于：

- GPT-4o / GPT-4o-mini
- Claude 3.5 Sonnet / Opus
- DeepSeek-V4
- Gemini 1.5 Pro / Flash
- 本地部署的 vLLM / Ollama 代理

## 三、两种模式定义

用户可在设置中全局选择以下两种模式之一，也可按场景单独覆盖：

### 3.1 模式对比

| 模式         | 说明                                                    | 适用场景                              |
| :----------- | :------------------------------------------------------ | :------------------------------------ |
| **本地智能** | 所有 AI 任务使用本地模型（Embedding + Reranker + Qwen） | 隐私优先、无网络、低成本              |
| **云端智能** | 所有 AI 任务使用云端 API（GPT/Claude/DeepSeek 等）      | 追求最佳质量、有网络、可接受 API 费用 |

### 3.2 用户选择优先级

| 优先级   | 覆盖范围     | 说明                                               |
| :------- | :----------- | :------------------------------------------------- |
| **最高** | 临时切换     | 在具体操作时（如执行 Skill），临时选择不同模式     |
| **中**   | 场景级覆盖   | 在全局模式下，对特定任务类型单独指定路由           |
| **最低** | 全局模式切换 | 在设置中选择 "本地智能" 或 "云端智能" 作为默认模式 |

## 四、完整任务路由表

### 4.1 隐私关键型任务（默认本地）

| 任务类型   | 本地智能                      | 云端智能            | 用户可覆盖 | 说明                         |
| :--------- | :---------------------------- | :------------------ | :--------- | :--------------------------- |
| 内容向量化 | ✅ 本地                       | ✅ 云端（通过 API） | ✅         | 用户原始内容→向量，隐私敏感  |
| 语义检索   | ✅ 本地                       | ✅ 本地             | ❌         | 检索在本地执行，结果不出设备 |
| 结果重排序 | ✅ 本地                       | ✅ 云端             | ✅         | 精排可走云端提升精度         |
| 语义拆分   | ✅ 本地（jina+Qwen）          | ✅ 云端             | ✅         | 原始文本拆分，隐私敏感       |
| 合规检查   | ✅ 本地                       | ❌ 不支持           | ❌         | 内容审查必须本地，不送云端   |
| 概念提取   | ✅ 本地（embedding+算法+LLM） | ✅ 云端（LLM）      | ✅         | 默认本地，云端质量更高       |
| 主题检测   | ✅ 本地（embedding+聚类+LLM） | ✅ 云端（LLM）      | ✅         | 同上                         |

### 4.2 文本生成型任务（可灵活切换）

| 任务类型             | 本地智能      | 云端智能       | 用户可覆盖 | 说明                         |
| :------------------- | :------------ | :------------- | :--------- | :--------------------------- |
| 短摘要（<300 词）    | ✅ Qwen3.5-4B | ✅ GPT-4o-mini | ✅         | 本地可胜任，云端质量更高     |
| 概念命名和相似检测   | ✅ Qwen3.5-4B | ✅ GPT-4o-mini | ✅         | 同上                         |
| 主题命名和相似度检测 | ✅ Qwen3.5-4B | ✅ GPT-4o-mini | ✅         | 同上                         |
| 润色（<500 词）      | ✅ Qwen3.5-4B | ✅ GPT-4o-mini | ✅         | 同上                         |
| 续写（<500 词）      | ✅ Qwen3.5-4B | ✅ GPT-4o-mini | ✅         | 同上                         |
| 改写（<500 词）      | ✅ Qwen3.5-4B | ✅ GPT-4o-mini | ✅         | 同上                         |
| 概念演化摘要         | ✅ Qwen3.5-4B | ✅ GPT-4o      | ✅         | 需对比历史，本地质量可能不足 |
| 模式发现             | ✅ Qwen3.5-4B | ✅ GPT-4o      | ✅         | 同上                         |

### 4.3 复杂推理型任务（默认云端）

| 任务类型            | 本地智能            | 云端智能         | 用户可覆盖 | 说明                         |
| :------------------ | :------------------ | :--------------- | :--------- | :--------------------------- |
| 矛盾检测            | ⚠️ Qwen（质量下降） | ✅ GPT-4o/Claude | ✅         | 本地可做但质量有限           |
| 知识缺口识别        | ⚠️ Qwen（质量下降） | ✅ GPT-4o/Claude | ✅         | 同上                         |
| 长文生成（>500 词） | ⚠️ Qwen（质量下降） | ✅ GPT-4o/Claude | ✅         | 同上                         |
| 长摘要（>300 词）   | ✅ Qwen3.5-4B       | ✅ GPT-4o-mini   | ✅         | 本地可做但质量有限           |
| 深度推理            | ❌ 不支持           | ✅ GPT-4o/Claude | ❌         | 本地模型无法胜任             |
| 跨领域关联          | ❌ 不支持           | ✅ GPT-4o/Claude | ❌         | 需要外部知识库，本地无法完成 |

## 七、渐进式加载策略

| 阶段               | 触发时机            | 下载/加载内容                                                | 大小    | 用户感知                                 |
| ------------------ | ------------------- | ------------------------------------------------------------ | ------- | ---------------------------------------- |
| **首次启动引导**   | 首次启动            | 引导用户选择启用本地智能和/或云端智能                        | -       | 引导界面，用户选择智能模式               |
| **启用本地智能**   | 用户确认启用        | jina-embeddings-v3 + bge-reranker-v2-m3 + Qwen3.5-4B（推荐） | ~4.5 GB | 一键下载全部 3 个模型，约 5-10 分钟      |
| **启动云端智能**   | 用户选择启用        | 无下载                                                       | -       | 选择服务商并填入 API Key，可设置月度限额 |
| **运行时模型加载** | 首次调用生成任务    | 将所选语言模型载入内存（从磁盘）                             | ~2.5 GB | 冷启动约 2-3 秒，后续热启动 <200ms       |
| **空闲卸载**       | 生成任务结束 5 分钟 | 释放语言模型内存                                             | -       | 无感知，下次调用重新加载                 |

## 八、总结：组件速查表

| 组件                          | 是否必须 | 下载时机     | 大小    | 归属模式            |
| ----------------------------- | -------- | ------------ | ------- | ------------------- |
| jina-embeddings-v3            | 是       | 首次启动引导 | 1.15 GB | 本地智能 + 云端智能 |
| bge-reranker-v2-m3            | 是       | 首次启动引导 | 1.15 GB | 本地智能 + 云端智能 |
| 本地语言模型（如 Qwen3.5-4B） | 是       | 首次启动引导 | 2.5 GB  | 仅本地智能          |
| 云端 API 配置                 | 否       | 用户手动配置 | -       | 仅云端智能          |
| 运行时层（MLX/llama.cpp）     | 是       | 打包在应用中 | ~50 MB  | 本地智能            |
| LanceDB 向量库                | 是       | 首次运行创建 | -       | 本地智能 + 云端智能 |

**护城河声明**：Pentip 的长期价值不在于具体模型，而在于 **文件优先的知识体系 + 长期个人语义索引**——即对用户 Markdown 文件的持久化语义索引和知识网络建模，这是任何通用模型无法替代的。
