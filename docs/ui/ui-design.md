# PenTip UI 概要设计文档

## 1. 概述

### 1.1 产品背景

PenTip 是一个 AI-native Cognitive OS（认知操作系统），基于 Electron + Vue3 + TypeScript 构建，专注于 Local-first 理念，让用户的文档、Prompt、模板完全保存在本地。

### 1.2 设计目标

- **Block First**：最小单位不是文档，而是 Block（块），一切都是 Block
- **AI Native**：AI 不是插件，而是工作流本身
- **Local-first**：用户数据完全保存在本地，隐私安全
- **语义链接**：AI 自动建立知识关联
- **自动结晶**：思维流自动结晶为结构化主题和知识体系

### 1.3 设计原则

1. **简洁直观**：清晰的信息层级，操作触手可及
2. **操作高效**：常用操作触手可及，减少操作步骤
3. **智能辅助**：AI 能力自然融入，不打断用户心流
4. **隐私优先**：所有数据本地存储，无需担心隐私泄露

## 2. 整体布局结构

### 2.1 布局概览

应用采用**二栏布局**（左侧导航 + 右侧内容区），各内容页可定义自己的内部布局（如创作工作台为三栏）。

```
│              │ (当前激活模块对应的页面)                                       │
```


### 2.2 区域说明

| 区域 | 说明 |
| --- | --- |
| **顶部栏** | 应用标题 + 菜单按钮 + 窗口控制按钮 + 设置/主题切换按钮 |

### 3.2 作品卡片

每个作品以卡片形式展示：

- **元信息**：Block 数量 / 字数 / 更新时间

- 新建按钮弹出 ProjectEditModal

| **编辑器区域** | 多 Tab 页面，文件树点击文件在新 Tab 中打开，用户可关闭 Tab |

- **自动保存**：内容修改后自动保存，无需手动操作
- **编辑器独立**：Tiptap 编辑器与 Block 无直接关系，编辑器用于编辑作品文件内容
- **左侧 Tab 切换**：「文件」显示文件树；「记录」显示该作品关联的历史 Block 列表
- **AI 面板**：提供 AI 辅助功能，如续写、总结、翻译等

### 5.2 功能定义

- 点击卡片可展开查看详情

## 6. 记录模块（Journal / Capture）

### 数据流说明
在"文件优先，数据库索引"架构下，记录模块的数据来源变更为文件系统：
- 用户输入的内容直接追加到 `{workspace}/journal/{YYYY-MM-DD}.md` 文件中
- 界面展示时，系统从文件读取原始内容，结合 SQLite 索引（AI 摘要、标签等）进行增强展示
- AI 处理结果（概念、主题、语义关联）从索引库获取，不写回 .md 文件

### 6.1 页面布局

```
┌──────────────────────────────────────────────┐
│ 日期分组标题                                   │
├──────────────────────────────────────────────┤
│ Block 1 (内容 + 操作按钮)                     │
│ Block 2 (内容 + 操作按钮)                     │
│ ...                                          │
├──────────────────────────────────────────────┤
│ 日期分组标题                                   │
├──────────────────────────────────────────────┤
│ Block 3 (内容 + 操作按钮)                     │
│ ...                                          │
├──────────────────────────────────────────────┤
│ [底部输入框...]                                │
│ 提示文字                                      │
└──────────────────────────────────────────────┘
```

### 6.2 功能说明

- 按日期分组的 Block 列表（时间倒序）
- 每个 Block 支持：查看、编辑、删除
- 底部输入框（DeepSeek 风格）用于快速创建新 Block
- 默认加载最近几天的数据，滚动加载更多（待优化）

### 6.3 状态处理

- **加载状态**：使用 Naive UI `n-spin` 组件
- **空状态**：使用 Naive UI `n-empty` 组件
- **错误状态**：使用 Naive UI `n-alert` 或 `n-notification` 组件

## 7. Block 交互

### 7.1 Block 定义

Block 是"文件内容的语义索引单位"，而非数据存储主体。Block 的原始内容存储在 `.md` 文件中，数据库中的 Block 记录作为索引（AI 摘要、标签、语义关联等），用于加速检索和增强展示。
Block 可以是想法、待办、引用、语录、附件等类型。

### 7.2 查看模式

- Block 以 Markdown 渲染内容展示
- 悬停时显示操作按钮（编辑、删除）
- 无拖拽交互

### 7.3 编辑模式

- 点击编辑按钮进入编辑模式
- 使用 Tiptap 编辑器进行内容修改
- 支持 Markdown 格式
- 保存后自动刷新列表

### 7.4 Block 操作

| 操作 | 说明 |
| --- | --- |
| 编辑 | 进入编辑模式修改内容 |
| 删除 | 删除该 Block |
| 设为备忘 | 标记为备忘类型 |

## 11. 页面路由

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 重定向 | 根据 `config.isFirstLaunch` 判断跳转 Welcome 或 Capture |
| `/welcome` | Welcome 视图 | 首次进入应用时展示 |
| `/capture` | Capture 视图 | 记录模块默认页（Journal 视图） |
| `/think` | 思考模块 | 概念与主题管理（待实现） |
| `/projects` | 作品列表 | 创作模块入口 |
| `/projects/:id` | 创作工作台 | 作品编辑器（待实现） |

### 11.1 首次进入逻辑

- 应用首次启动时，读取配置文件（electron-store）中的 `isFirstLaunch` 字段
- 若为 `true`，跳转到 `/welcome` 展示欢迎页
- 用户完成工作空间选择等初始化后，将 `isFirstLaunch` 设为 `false`
- 非首次进入直接跳转到 `/capture`
