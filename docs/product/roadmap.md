# Wrisp 版本路线图

---

## 一、四阶段框架

> 基于 Free/Pro 商业策略，按商业里程碑划分为四个阶段。每个阶段对应一个商业目标，详细计划见独立文件。

| 阶段 | 名称 | 商业目标 | 收费 | 工程版本 | 详细文件 |
|------|------|----------|------|----------|----------|
| **Phase 1** | Free MVP | 验证"记录即整理"核心价值，获取用户量 | 免费（AGPLv3） | V0.1.0 ~ V1.0.0 | [phase1-free-mvp.md](phase1-free-mvp.md) |
| **Phase 2** | Pro 核心版 | 验证付费意愿，Free → Pro 转化 | $9/月 或 $90/年 | V1.x.0 | [phase2-pro-core.md](phase2-pro-core.md) |
| **Phase 3** | 平台生态 | 构建知识管理生态，开放扩展 | Pro 订阅 | V2.x.0 | [phase3-platform.md](phase3-platform.md) |
| **Phase 4** | Team 版 | 从个人工具走向团队平台 | $15/用户/月 | V3.x.0 | [phase4-team.md](phase4-team.md) |

---

## 二、各阶段功能范围总览

### Phase 1：Free MVP — 本地 AI 知识管理工具

| 能力域 | 核心功能 |
|--------|---------|
| **记录** | Block 编辑器、Journal 每日日志、输入模板、@提及、#标签/[[页面]]、日历导航 |
| **整理** | 语义拆分、向量化、语义链接、概念提取、主题聚类、FTS5 + 语义搜索 |
| **创作** | Project 作品空间、AI 续写/润色/改写、语义检索引用、AI 大纲生成、模板市场 |
| **基础设施** | 单 AI Provider、本地模型管理、SQLite + LanceDB、Electron 打包、i18n、自动更新 |

### Phase 2：Pro 核心版 — 深度洞察 + 便捷创作 + 跨设备

| 优先级 | 能力域 | 核心功能 |
|--------|--------|---------|
| **P0** | 推演 | 反思流全套（模式发现 + 矛盾检测 + 知识缺口 + 趋势分析）、AI 周报/月报 |
| **P0** | 创作增强 | 上下文自动召回、内联 AI 对话、多格式导出、版本历史 + diff |
| **P0** | 同步 | E2E 加密云同步、选择性同步、移动端快速捕获 |
| **P1** | 整理增强 | 概念网络可视化、跨日期关联、决策/行动项提取 |
| **P2** | AI 增强 | 多 Provider 智能路由、用量监控 |

### Phase 3：平台生态 — 从工具到平台

| 能力域 | 核心功能 |
|--------|---------|
| **插件系统** | 三层插件（Data / Cognitive / Output）、插件市场 |
| **开放接口** | RESTful API、MCP 协议、Webhook 通知 |
| **多源输入** | 语音转写、Web Clip、邮件转发、批量导入（Obsidian/Notion/Logseq） |
| **认知引擎增强** | 跨领域关联、主题演化树、知识图谱交互 |
| **Web 访问** | 浏览器端只读 + 快速追加 Block |

### Phase 4：Team 版 — 团队知识协作

| 能力域 | 核心功能 |
|--------|---------|
| **共享知识空间** | 团队工作空间、权限管理、成员管理 |
| **团队知识图谱** | 团队概念网络、知识贡献统计、知识缺口分析 |
| **协作编辑** | 实时协作（CRDT）、评论与讨论、团队版本历史 |
| **团队推演** | 团队反思流、团队 AI 周报 |
| **管理后台** | 用量统计、安全审计、SSO 集成 |

## 四、阶段依赖关系

```
Phase 1 (Free MVP — 本地 AI 知识管理)
  └── Phase 2 (Pro 核心版 — 深度洞察 + 便捷创作 + 跨设备)
        └── Phase 3 (平台生态 — 插件 + API + 多源输入)
              └── Phase 4 (Team 版 — 团队协作)
```

- **Phase 1 是基础**：没有可用的 Free 版，就没有用户量，后续无从谈起
- **Phase 2 是商业化验证**：在 Free 用户积累后，通过 Pro 能力验证付费意愿
- **Phase 3 是生态扩展**：PMF 验证后，开放平台能力，让社区贡献长尾功能
- **Phase 4 是增长引擎**：个人 Pro 验证后，向团队市场扩展，提升 ARPU
