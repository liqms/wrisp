## 二、技术方案要点

### 插件系统架构

```
┌─────────────────────────────────────────────┐
│              插件运行时（Plugin Runtime）       │
│  沙箱隔离 · 权限控制 · 生命周期管理            │
└─────────────────────────────────────────────┘
                      │
        ┌─────────────┼─────────────┐
        │             │             │
┌───────▼───┐  ┌──────▼────┐  ┌────▼──────┐
│ Data 层    │  │ Cognitive │  │ Output 层 │
│ PDF/OCR    │  │ Summarize │  │ Blog/Docs │
│ WebClip    │  │ Reflect   │  │ Slides    │
│ Import     │  │ Reason    │  │ Publish   │
└────────────┘  └───────────┘  └───────────┘
```

- 插件使用 TypeScript/JavaScript 编写，沙箱隔离执行
- 权限模型：声明所需权限（文件读写、网络访问、AI 调用），用户审批
- API 层：暴露 Wrisp 内部能力（知识库读写、AI 推理、UI 扩展点）

### MCP Server

- 将 Wrisp 知识库暴露为 MCP Server，其他 AI Agent 可通过 MCP 协议查询/写入
- 支持的工具：search_knowledge（语义搜索）、get_concept（概念详情）、get_topic（主题详情）、create_journal（创建记录）
- 认证：API Key + 权限范围控制

### 批量导入

- Obsidian：直接打开 .md 文件目录，保留双链和标签
- Notion：通过 Notion API 导出，转换为 Markdown
- Logseq：直接打开 .md 文件目录，兼容大纲格式
- 导入后自动触发 AI 索引（向量化 + 语义链接 + 概念提取）
