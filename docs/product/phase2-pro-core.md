## 二、技术方案要点

### 反思流引擎

```
语义块库 → 模式分析（频率/周期/聚类）→ 模式发现
         → 矛盾比对（同概念不同时间观点对比）→ 矛盾检测
         → 网络分析（概念网络断裂检测）→ 知识缺口
         → 时间统计（概念/主题数量变化）→ 趋势分析
         → 摘要生成（周/月活动汇总）→ AI 周报/月报
```

- 后台定时执行（每日/每周），不阻塞用户操作
- 每个洞察提供"为什么这么认为"的解释（可追溯）
- 用户可确认/忽略/深入探索每个洞察

### E2E 加密云同步

- 同步协议：Operation-based（CRDT 思路），非文件级 diff，避免冲突
- 加密方案：客户端加密后上传，服务器只存储密文
- 冲突处理：自动合并可合并的操作，不可合并的提示用户选择
- 增量同步：只同步变更操作，非全量

### 移动端快速捕获

- 技术方案：React Native / Flutter 轻量 App
- 核心场景：打开 → 输入 Block → 保存 → 关闭，< 3 秒完成
- 不做全功能编辑器，只做快速捕获入口
- 数据通过云同步到桌面端

### 上下文自动召回

- 触发时机：用户在 Project 编辑器中写作时，后台持续分析当前内容
- 召回逻辑：当前内容向量化 → 检索相关语义块 → 去重 → 排序 → 侧边栏展示
- 用户操作：可展开查看、一键插入引用、忽略不相关的
