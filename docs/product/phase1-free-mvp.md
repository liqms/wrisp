# Phase 1：Free MVP — 本地 AI 知识管理工具

> **商业目标**：验证"记录即整理"核心价值，获取用户量，吸引 Obsidian/Logseq 用户迁移
>
> **收费模式**：免费（AGPLv3 开源）
>
> **对应工程版本**：V0.1.0 ~ V1.0.0

---

## 一、功能范围

| 能力域 | 核心功能 | 说明 |
|--------|---------|------|
| **记录** | Block 编辑器（Tiptap 3） | 大纲层级、Tab 缩进、TODO 状态循环、拖拽排序 |
| | Journal 每日日志页 | 每天自动对应 journal/YYYY-MM-DD.md，打开即编辑 |
| | 输入模板（Slash 命令） | 预设格式快速插入（会议纪要、TODO、灵感等） |
| | @提及 | 提及人/项目/概念，自动补全与链接 |
| | #标签 / [[页面]] | 自动补全已有标签、页面/概念，写入 Markdown 双链 |
| | 日历导航 | 按日期浏览 Journal，日历视图快速跳转 |
| **整理** | 语义拆分 | AI 根据语义边界自动拆分长文本为语义块 |
| | 向量化 | jina-embeddings-v3 子进程异步生成，LanceDB IVF-PQ 索引 |
| | 语义链接 | 新语义块入库 → 自动搜索相似语义块 → 建立关联 |
| | 概念提取 | 从语义块中提取高频概念实体，演化摘要 |
| | 主题聚类 | 高频概念簇自动生成 Topic，支持编辑/软删除/恢复 |
| | FTS5 全文搜索 | 中文分词 + 全文索引，毫秒级内容搜索 |
| | 语义搜索 | 向量检索 + bge-reranker-v2-m3 重排序 |
| **创作** | Project 作品空间 | 项目 → 页面两级层次，支持文章/报告/小说等类型 |
| | AI 续写/润色/改写 | 基于上下文 + 关联语义块续写，选中文本润色/改写 |
| | 语义检索引用 | 创作时手动搜索历史语义块，一键插入引用链接 |
| | AI 大纲生成 | 基于关联语义块自动生成作品结构 |
| | 模板市场 | 社区共享模板（PRD 模板、周报模板、读书笔记模板等） |
| **基础设施** | 单 AI Provider | 用户自配 API Key（OpenAI / Claude / DeepSeek / Qwen） |
| | 本地模型管理 | 模型下载/切换/删除，自动适配硬件 |
| | SQLite + LanceDB 存储 | better-sqlite3 WAL 模式，FTS5 全文索引 |
| | Electron 三平台打包 | Windows / macOS / Linux 安装包 |
| | 中英文 i18n | 完整国际化覆盖 |
| | 自动更新 | 版本检查与增量下载安装 |

## 二、工程版本计划

### V0.1.0 — 项目搭建与 Journal 基础

**目标**：打通开发环境，实现 Journal 每日日志页编辑。

| 类别 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 开发 | 项目初始化 | Electron + Vue3 + TypeScript + Vite，pnpm 管理依赖 | 项目骨架，`pnpm dev` 可启动 |
| 开发 | 主进程搭建 | BrowserWindow 初始化、IPC 通信基础、窗口管理 | 主进程入口，IPC 通道可用 |
| 开发 | Renderer 初始化 | Vue app + Naive UI + Pinia + Vue Router + i18n | 基础页面路由，组件库可用 |
| 开发 | SQLite 数据库 | better-sqlite3 连接、WAL 模式、migration 机制 | 数据库初始化脚本，基础 DAO 层 |
| 开发 | 数据表设计 | file_index、semantic_chunks、concepts、topics、semantic_links 等 | DDL 迁移文件，表创建验证 |
| 开发 | Journal 文件管理 | 读取/写入 journal/YYYY-MM-DD.md，每日页面切换 | Journal 文件管理 API |
| 开发 | 块编辑器 | Tiptap 3 行内编辑、Enter 换行、Tab 缩进、TODO 状态循环 | 块编辑器核心 |
| 开发 | file_index 管理 | 文件哈希计算、同步状态管理、增量检测 | 文件索引模块 |
| 开发 | FTS5 全文搜索 | 中文分词 + 全文索引，搜索 API | 毫秒级内容搜索 |
| 开发 | #标签 / [[页面]] | 自动补全已有标签、页面/概念、写入 Markdown | 双链支持 |
| 开发 | 配置存储 | electron-store 集成，用户偏好持久化 | 配置读写模块 |
| AI 功能 | AI API 抽象层 | 统一接口封装（本地模型 / OpenAI / Claude / DeepSeek / Qwen） | `ai-service` 模块，可切换后端 |
| UI/UX | 基础布局 | 应用壳（标题栏、侧边栏、主内容区） | 可导航的空白应用 |
| UI/UX | Journal 视图 | 每日日志页，Markdown 编辑区，文件名指示器 | 可编辑和浏览日志的界面 |

| UI/UX | 日历导航 | 日历视图，按日期快速跳转 Journal 页面 | 日历导航组件 |
| UI/UX | 输入模板 | Slash 命令菜单，预设模板快速插入 | 模板选择 UI |
| 推广/社区 | GitHub Repo | AGPLv3 License + README + CONTRIBUTING | 公开仓库，文档齐全 |
| 推广/社区 | Alpha 版本发布 | GitHub Release alpha 分支 | 可下载的 alpha 版本 |
| 推广/社区 | Early Adopter 招募 | 收集 10-20 个早期用户的联系方式 | 早期用户列表 |
| 推广/社区 | 反馈收集 | 收集 early adopter 对记录体验的反馈 | 反馈记录 |

**依赖**：无（从零开始）

**完成标准**：`pnpm dev` 启动 Electron 窗口，SQLite 数据库可读写，IPC 通信正常。可创建/编辑/删除 Journal 内容，内容持久化为 .md 文件，FTS5 搜索可用。

### V0.2.0 — AI 索引 + 语义链接

**目标**：用户记录后自动生成 Embedding 和语义链接。

| 类别 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 开发 | Embedding Worker | 子进程加载 jina-embeddings-v3，异步生成向量 | 不阻塞 UI 的向量生成服务 |
| 开发 | LanceDB 集成 | 向量表创建、IVF-PQ 索引配置、ANN 搜索 | 向量存储与检索模块 |
| 开发 | 语义链接生成 | 新语义块入库 → 自动搜索相似语义块 → 建立关联 | semantic_links 表写入，关联查询 API |
| AI 功能 | jina-embeddings-v3 | 模型下载、加载、推理 pipeline | 1536 维向量输出验证 |
| AI 功能 | bge-reranker-v2-m3 | 重排序集成，提升语义搜索准确性 | 搜索结果重排序 pipeline |
| UI/UX | 语义链接展示 | 语义块详情面板展示关联语义块列表 | 关联语义块卡片 UI |
| UI/UX | 异步状态指示 | Embedding 生成中的 Loading 状态 | 生成进度指示器 |
| 推广/社区 | 演示视频 | 录制语义链接功能演示 | 1-2 分钟演示视频 |
| 推广/社区 | 反馈收集 | 收集语义链接准确性、相关性反馈 | 准确率统计 |

**依赖**：V0.1.0 完成（需要 Journal 记录和文件存储）

**完成标准**：创建 Journal 条目后自动生成 Embedding 存入 LanceDB，自动关联历史相似语义块并在 UI 展示。

### V0.3.0 — 语义拆分 + 主题聚类

**目标**：后台语义拆分 + 自动主题聚类生成。

| 类别 | 任务 | 说明 | 产出 |
|------|------|------|------|
| 开发 | 语义拆分 Worker | Qwen3.5-4B 子进程，AI 语义拆分长文本 → 语义块列表 | 拆分服务，支持 2000+ 字长文本 |
| 开发 | 主题聚类引擎 | 高频概念检测（阈值可配置）→ 语义聚类 → 自动创建 Topic | 主题聚类核心逻辑 |
| 开发 | 主题生命周期 | 自动创建（active）、软删除（deleted）、恢复、彻底删除 | 主题数据层 API |
| 开发 | 概念提取引擎 | 从语义块中提取高频概念实体，更新 evolving_summary | 概念提取与演化摘要 |
| AI 功能 | Qwen3.5-4B 集成 | 本地模型加载、推理 pipeline（语义拆分 + 摘要生成） | 本地 LLM 推理服务 |
| AI 功能 | 语义聚类 | 基于 Embedding 的语义块聚类算法 | 聚类结果输出 |
| UI/UX | 主题卡片列表 | 卡片网格（名称、语义块/概念数、更新时间）、排序/筛选 | 主题列表页面 |
| UI/UX | 主题详情面板 | 右侧滑出，摘要、关联概念标签、语义块时间线列表 | 主题详情 |
| UI/UX | 回收站 | 已删除主题管理，支持恢复和彻底删除 | 回收站入口 + 操作面板 |
| 推广/社区 | Beta 版本发布 | GitHub Release beta 分支 | 可下载的 beta 版本 |
| 推广/社区 | 社区推广 | Hacker News / Reddit / V2EX 发帖 | 帖子链接 + 反馈收集 |

**依赖**：V0.2.0 完成（需要 Embedding 和 LanceDB）

**完成标准**：用户记录后后台自动拆分语义块、提取概念、聚类生成主题，主题卡片列表和详情面板可用，支持软删除与恢复。
