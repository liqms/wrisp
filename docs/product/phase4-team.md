## 二、技术方案要点

### 团队同步架构

```
成员 A（本地） ←→  团队同步服务器  ←→ 成员 B（本地）
      │              │                    │
      ▼              ▼                    ▼
  本地 .md 文件   团队知识库（加密）   本地 .md 文件
      │              │                    │
      └──────────────┼────────────────────┘
                     ▼
              团队 AI 索引层
         （共享概念/主题/语义链接）
```

- 本地优先保留：每个成员本地仍有完整 .md 文件副本
- 团队同步服务器：存储团队共享知识库，E2E 加密
- 冲突处理：CRDT 自动合并，不可合并的提示用户选择
- 权限同步：权限变更实时同步到所有成员

### 实时协作

- 基于 CRDT（Yjs/Automerge）实现实时协同编辑
- 每个 Block 是一个 CRDT 文档片段
- 离线编辑后上线自动合并
- 协作状态指示：谁在线、谁在编辑哪个 Block

### 企业安全

- 数据加密：传输层 TLS + 存储层 AES-256
- SSO 集成：支持 SAML 2.0 和 OIDC
- 审计日志：所有操作记录（谁、何时、做了什么）
- 数据导出：管理员可导出团队全部数据（Markdown + 索引）
- 合规：GDPR / 数据驻留选项
