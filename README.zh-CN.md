# Wrisp

[English](README.md) | **中文**

**面向深度思考者的 AI-native 知识工作台。**

记录零负担，召回自动化，让每一次输出都有据可依。

---

## 为什么是 Wrisp

我们每天都在捕获碎片：会议里的一句反馈、通勤时的一个想法、竞品的一次更新。但当你真正要写一份 PRD、做一次复盘时，却常常找不到当初那条关键信息。

通用笔记太松散，AI 代劳工具又让人失去对知识的掌控感。

Wrisp 坚持一个原则：**AI 辅助，而非替代**。AI 负责理解、关联、聚类与召回；判断、整理与记忆，始终属于你。

---

## 核心特点

| 特性 | 描述 |
|------|------|
| **Block First** | 最小单位是 Block，不是文档。碎片输入零组织压力，回车即存 |
| **AI 辅助，而非替代** | AI 提出关联建议、聚类候选、召回素材，你确认或拒绝。知识进入大脑，而非只存在电脑里 |
| **Local-first** | 所有数据本地存储，未公开的调研、Roadmap、竞品分析不会离开你的设备 |
| **决策可追溯** | 每个需求、每次砍需、每个方案选择的背后依据，通过语义链接随时召回 |
| **自动结晶** | 碎片输入自动聚类为主题，随时间累积成知识体系 |
| **反思流** | 持续发现思维模式与决策矛盾，做你思考的“辅助大脑” |

## 典型场景

### 产品经理

- 会议上听到一句用户反馈，回车即存，不用想放哪个文件夹
- 写 PRD 时，AI 自动召回上月的调研、竞品分析、用户访谈
- 三个月后老板问“为什么砍了这个需求”，一键召回当时的讨论和决策依据

### 研究者 / 分析师

- 阅读论文时随手记录观点，AI 自动关联到已有笔记
- 写报告时，相关素材自动浮现，从组装开始而非从零起手

### 内容创作者

- 灵感碎片自动聚类成主题，写作时按主题调用
- 长期追踪某个话题的思考演化，形成个人观点时间线

### 知识工作者

- 会议纪要、学习笔记、项目复盘统一沉淀
- 需要时语义检索，毫秒级召回历史记录

## 核心功能

### Journal 日志输入

碎片想法、会议纪要、竞品观察、数据洞察，统一以 Block 形式零组织成本输入。支持 Markdown 语法、`[[双链]]`、`#标签`。

### Wiki 智能整理

AI 自动建立语义链接、聚类主题、可视化概念网络。所有 AI 建议均可人工确认、编辑或拒绝。

### Project 结构化输出

撰写 PRD、报告、文章时，AI 召回历史素材，从组装开始而非从零起手。支持 Markdown 导出。

### Reflection 反思流

自动发现思维模式、决策矛盾与兴趣漂移，以洞察卡片形式呈现，帮助你更全面地审视自己的知识体系。

## 快速开始

### 下载安装

前往 [Releases 页面](https://github.com/liqms/wrisp/releases) 下载对应平台的安装包：

| 平台 | 安装包 |
|------|--------|
| **Windows** | `.exe`（NSIS 安装包）或 `.exe`（便携版） |
| **macOS** | `.dmg` 或 `.pkg` |
| **Linux** | `.deb` / `.rpm` / `.AppImage` |

下载后双击安装即可使用。

### 首次使用

1. 启动应用，选择数据存储目录（默认在用户文档下）
2. 在设置中配置 AI 模型（支持 OpenAI / Claude / DeepSeek / Qwen / 本地模型）
3. 进入 Journal 页面，开始记录你的第一条想法

## 技术栈

- **前端框架**: Vue 3 + TypeScript + Composition API
- **构建工具**: Vite
- **桌面框架**: Electron
- **状态管理**: Pinia
- **路由**: Vue Router
- **UI 组件**: Naive UI
- **编辑器**: Tiptap 3（块编辑器）
- **数据库**: SQLite（better-sqlite3）+ LanceDB（向量索引）
- **AI 网关**: 多 Provider 适配（OpenAI / Claude / DeepSeek / Qwen / 本地模型）
- **代码规范**: ESLint + TypeScript
- **打包工具**: electron-builder
